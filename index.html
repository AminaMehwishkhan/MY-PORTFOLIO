AI Video Frame Interpolation System

A CUDA-accelerated pipeline that generates smoother, high-FPS video from lower-frame-rate source footage.

Built around the RIFE model, with CUDA acceleration, CPU multiprocessing, CUDA batching, and multithreaded producer-consumer processing with frame caching. Supports 60/120 FPS output modes with FPS verification and per-frame performance benchmarking.

An offline, privacy-first assistant that reads and validates government-form images locally.
